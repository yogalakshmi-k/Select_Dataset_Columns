# Day 18 - Select Dataset Columns

## Internship
AI & ML Internship - Level 1

## Task Description
This task demonstrates how to select specific rows and columns from a dataset using Pandas in Python.

## Objective
To understand how to access specific parts of a DataFrame using the `loc` and `iloc` methods.

## Tools Used
- Python
- Pandas
- Google Colab

## Dataset
A sample student dataset containing the following columns:
- Name
- Age
- Department
- Marks

## Concepts Covered
1. Creating a Pandas DataFrame.
2. Selecting a single column.
3. Selecting multiple columns.
4. Selecting rows using `loc`.
5. Selecting rows and columns using `loc`.
6. Selecting rows using `iloc`.
7. Selecting rows and columns using `iloc`.
8. Accessing a single value from a DataFrame.

## Difference Between loc and iloc
- `loc` selects data using row labels and column names.
- `iloc` selects data using integer positions.

## Expected Output
The program displays the complete dataset and demonstrates how to select specific rows, columns, and individual values.

## Result
Successfully implemented Pandas `loc` and `iloc` methods to select specific rows and columns from a dataset.

## Conclusion
This task helped me understand DataFrame indexing and data selection using Pandas in Python.
